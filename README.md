# 评测集工作台

面向通用 LLM、垂直领域模型与微调模型的评测集构建工具：从源文档生成候选题，经业务专家提出建议、技术人员审核，再收录到冻结版本。

个人项目，AI 辅助开发。当前完成的是评测集构建与审核流程；模型自动批量作答、自动评分及模型对比报告属于后续规划。

```text
源文档 → 模型与提示词 → 候选评测集 → 业务专家建议 → 技术审核 → 冻结版本
                                                         ↓
                                              分类筛选与样本分布查看
```

## 快速开始

完整模型密钥保存功能目前需要 Windows（使用 DPAPI 用户级加密）。安装 Node.js 22+、Python 3.10+ 后执行：

```powershell
python -m pip install -r requirements.txt
npm start
```

访问 `http://127.0.0.1:8765`，在“模型配置”中自行填写服务地址、模型 ID 和 API Key。也可双击 `启动工具.cmd`。

本发布版首次启动为空工作台，不预置任何账号、客户文件、模型配置或真实评测集。可在任一审核页上传 [`examples/demo-dataset.json`](examples/demo-dataset.json) 或 [`examples/demo-dataset.jsonl`](examples/demo-dataset.jsonl) 体验审核流程；虚构源资料见 [`examples/demo-source.md`](examples/demo-source.md)。

运行数据会自动写入 `data/` 并被 Git 忽略。当前是本地单实例工具，尚无账号与角色权限；发布到公网前需要补充访问控制和部署适配。两个审核页是流程视图，并非已有的身份权限隔离。

发布内容的处理范围见 [PUBLIC_RELEASE.md](PUBLIC_RELEASE.md)。发布包校验：`python scripts/check-public.py --release`；日常源码检查：`python scripts/check-public.py`。

## 详细使用说明


当前功能：模型配置、模型连接测试、原始源文档上传与预览、多源文件 AI 生成评测集、提示词模板管理、业务专家审核、技术人员审核、冻结版本管理。顶部导航依次为“评测集的原始源文档”“源文件生成评测集”“业务专家审核”“技术人员审核”“冻结评测集”“提示词库”“模型配置”。

## 使用

1. 双击 `启动工具.cmd`，浏览器自动打开 http://127.0.0.1:8765 。
2. 点击右上角“添加模型配置”，填写配置名称、Base URL、API Key（服务无需鉴权时可留空）。
3. 在“模型管理”中填写模型 ID，每行一个。同一模型配置支持多个模型。
4. 选择测试模型，点击“测试连接”。工具会向模型发送“请只回复：连接成功”，展示模型回复、HTTP 状态和请求耗时。
5. 点击“保存模型配置”。名称、地址、模型列表、超时、密钥以及匹配当前配置的测试结果会保存在本机，刷新页面后仍然保留。

每张模型配置卡片提供“模型”“设置”“删除”操作。支持按名称、模型或地址搜索，以及刷新列表。“设置”内可以再次测试已保存的连接。API Key 留空表示保留原密钥；填写新值会替换密钥，勾选“清除已保存密钥”后保存可移除密钥。

API Key 使用 Windows DPAPI 加密，绑定当前 Windows 用户；列表和接口均不会返回密钥原文。迁移到其他账户或电脑时，需要重新填写密钥。旧版单模型配置首次打开时会自动迁移为模型配置。

服务在本机后台运行，关闭网页不会退出服务；双击 `停止工具.cmd` 可停止由启动脚本开启的服务。

## 评测集的原始源文档

打开 http://127.0.0.1:8765/files ，点击“上传文件”或拖拽文件到上传区，可一次选择多个文件。单个文件最多 50 MB，文件上传后自动保存在本机，刷新或重启工具仍能恢复。同名文件分别保存，不覆盖原文件。

下方列出文件名称、类型、大小和上传时间。点击文件名称或“查看详情”可查看内容，支持搜索和下载原文件。

每个文件的“操作”列提供“删除”。核对弹窗中的文件名后确认，文件即从源文档列表和已勾选项中移除；刷新或重启后仍保持删除状态。同名的其他文件、已生成的 JSON、审核内容及冻结版本不受影响。本机保留带删除标记的原文件归档，已有生成任务仍可读取原资料继续生成；已删除文件不再提供预览、下载或用于新建生成任务。

- CSV、TSV、XLSX、XLSM：表格预览，Excel 支持工作表切换。
- DOCX：按正文顺序显示标题、段落和表格。
- Markdown：支持简要排版预览与原文切换。
- TXT、JSON、JSONL 等文本：原文预览，识别 UTF-8、带 BOM 的 UTF-16/UTF-32 和 GB18030。
- PDF：文字预览；扫描件不进行 OCR。
- 其他格式均可上传、查看基本信息并下载；旧版 DOC/XLS 建议另存为 DOCX/XLSX 后预览。

大文件仅展示部分内容：表格最多 200 行、60 列，文字约 20 万字符，PDF 最多前 20 页。完整原文件会保留。预览不会运行文件内的脚本、宏或 Markdown 中的 HTML，也不会向模型发送内容。

## 源文件生成评测集

在原始源文档页勾选 1–20 个文件，或用表头复选框全选当前文件搜索结果，点击“AI 生成评测集”。填写名称和题数（默认 200 题），选择已保存的模型配置与模型，可使用默认生成提示词，也可从提示词库选择模板并修改。模板中的自定义变量需填写；`{{参考资料}}`、`{{源文档}}`、`{{文件内容}}` 自动填入本批源文档内容，`{{题目数量}}` 为本批题数，`{{总题目数量}}` 为任务总题数。

点击“开始生成”才会向所选模型服务发送资料并产生模型调用。生成在本机后台分批运行，默认每批 5 题、单次超时 180 秒、输出上限 8,192 Token，可展开“分批与输出设置”调整。关闭网页后任务继续运行；停止本机服务则任务中断，重启后需点击“继续生成”。同一时间运行一个任务，最多保留 10 个排队或生成中的任务。

生成题数支持 1–1,000 道。生成批数严格等于“总题数 ÷ 每批题数”向上取整：例如 9 道题、每批 5 道为 2 批，依次生成 5 道和 4 道；资料分块数不会增加生成批数。资料多于生成批次时，按资料顺序均匀抽选参考内容，保持每批材料的大小限制；任务列表与详情显示抽选范围，少量题目不代表覆盖全部原题。模型格式校验失败时仍可能重试当前批次一次。此前因最低题数或旧分批规则失败的任务可以继续生成，已有题目保留；旧进度未满一批时先补齐该批，再生成剩余批次。

生成读取完整文件，独立于预览限制：包括 Excel 所有工作表及长单元格、CSV 多行单元格、DOCX 正文与表格、PDF 全部页面、Markdown 和纯文本、JSON/JSONL 记录。Excel 公式保留原文，宏不执行；Word 图片和批注、PDF 扫描图片不进行文字识别。旧版 DOC/XLS 需先转换格式。所选资料合计最多 200 万字符、10,000 段，单个表格行或 JSON 记录最多 60,000 字符；超出时明确报错并保留原文件，不静默截断正文。资料按段分批输入模型，每段获得稳定的 `SRC-xxxx` 引用，并记录文件、工作表/行号/页码等位置及可识别的原题 ID。

默认提示词参考原题、已有参考答案、专家结论/意见、口径落点提示和暴露的模型侧问题，要求自然简短的用户提问、离线自包含数据、符合专家意见的参考答案及可执行的评分标准。每题按顺序输出以下八个字段：

```text
Question、User Question、SELECT Data、answer、Scoring criteria、difficulty、Task family、source
```

每批校验 JSON 结构、必需字段、题数、重复的用户问题及来源引用。格式校验失败时重试当前批次一次；接口异常、空回复或输出截断会停止并显示原因。已完成批次立即保存，停止或失败后可下载已生成部分或继续剩余批次。继续时会核对源文件哈希及模型配置修订，避免混用变化后的源文件和模型配置；需要更改提示词或生成设置时请新建任务。

打开 http://127.0.0.1:8765/source-datasets ，可查看历史任务、生成进度和错误原因，按名称、源文件、模型搜索或按状态筛选。点击“查看题目”逐条查看完整字段、JSON、来源引用索引和使用的提示词。完整结果可“下载 JSON”或“送入审核”；送审成功后自动进入对应的业务专家审核页，并打开与上传评测集相同的“字段配置”，可填写描述和启用分类筛选。关闭或保存后刷新不会重复弹出，仍可随时点击审核页“字段配置”修改。两个审核页共用该评测集与配置，同一任务重复送入不会重复导入。生成结果是待审核材料，结构校验不代表事实与评分标准已通过专家审核。

每个任务的“操作”列提供“删除任务”。弹窗展示任务名称、状态和题数，确认后从列表移除；正在运行或排队的任务同时停止后续生成。已删除任务不再提供题目、下载、继续生成或送审入口，刷新或重启后不会重新出现。原始源文档、其他任务、已送审副本及冻结版本保留。本机保留任务及生成结果归档；删除运行任务会中止本机请求，已经发送至模型服务的请求可能仍按服务方规则计费。

## 提示词库

打开 http://127.0.0.1:8765/prompts ，点击“添加模板”，填写模板名称、分类、用途说明和提示词正文并保存。模板保存在本机，刷新页面或重启服务后仍然保留，支持搜索、分类筛选、编辑和删除。

提示词正文可使用 `{{变量名}}`，例如：

```text
请根据以下参考资料，生成 {{题目数量}} 道关于 {{领域}} 的评测题。

参考资料：
{{参考资料}}
```

点击模板的“使用模板”，填写变量后实时得到完整正文，再点击“复制完整提示词”即可粘贴到模型输入中。同名变量只填写一次，变量值中的特殊符号和换行会原样保留，填写变量不会改变已保存的模板。没有变量的模板可直接复制使用。

“复制原文”保留模板中的变量占位符。“从示例开始”提供一个可编辑的评测问题生成示例，只有点击保存后才会加入提示词库。

源文档页的生成弹窗可直接读取提示词库模板并自动填入源文档相关变量。选择、填写或复制模板本身不调用模型。

## 业务专家审核

打开 http://127.0.0.1:8765/expert-review 。此页与技术人员审核共用已导入的评测集，也支持上传 JSON 和 JSONL。题目列表、搜索、分页、全选和详情使用相同的界面与题目序号，专家可按“尚未填写”“有建议草稿”“已提交建议”继续处理。

点击题目后，左侧展示完整字段和原始题目 JSON，右侧填写专家修改建议，可说明题目、参考答案、查询数据或评分标准中的调整点。每道题的建议最多 20,000 个字符：

- **保存草稿**：保存到本机，刷新或重启后可恢复，技术人员此时看不到该草稿。同一页面切换题目时也会暂存尚未保存的输入；要在刷新后保留，需保存草稿。
- **提交给技术人员**：先保存当前输入，再提交建议；该题会回到技术人员的待审核列表。技术人员可查看提交时间、完整建议和历史提交记录。
- **提交所选建议**：可跨页勾选或全选，统一提交已保存的最新草稿。如果选中的题目没有草稿、草稿对应的题目已修改，或建议在其他页面被更新，整批不执行并提示原因。可先筛选“有建议草稿”再选择提交。

建议再次修改时先形成新草稿，原来已提交的内容继续对技术人员可见；再次提交后更新最新建议并保留历史。专家建议按评测集 ID 与稳定题号对应，同名文件、相同来源 ID 的其他导入不会串题。提交会更新审核修订号，防止技术人员的旧页面忽略新建议而直接操作。已冻结内容、原始上传文件和题目字段保持原样，建议作为审核记录单独保存，不混入评测题 JSON。

题目在技术人员修改后，旧建议会标记为“建议提交后题目已修改”，供继续核对。专家可从详情中的链接直接进入对应的技术审核题目。建议保存与提交均不调用模型。

## 技术人员审核

打开 http://127.0.0.1:8765/technical-review ，点击“上传评测集”或拖入一个 `.json` / `.jsonl` 文件。单个文件最多 20 MB、10,000 道题。JSON 支持顶层题目数组、单题对象，以及 `data`、`questions`、`items`、`records`、`dataset` 等常见包装结构。JSONL 每个非空行是一个完整的题目对象，不加外层数组或行尾逗号，空白行会跳过；字符串内换行使用 `\n` 转义。格式错误会显示具体行号并整批拒绝，不会导入一部分，也不影响之前导入的评测集。原文件按上传时的字节和扩展名保留，可通过“下载原始 JSON / JSONL”取回。

```jsonl
{"question":"问题一","answer":"答案一","type":"简答"}
{"question":"问题二","answer":"答案二","type":"简答"}
```

上传后按原文件顺序逐题展示。技术人员和业务专家的列表均根据上传文件中实际题目对象的 JSON key 自动生成数据列，保持原始名称，按字段首次出现的顺序排列；不再固定为“问题、难度、任务族、来源”。不同题目字段不一致时使用整个上传文件的 key 并集，翻页、筛选或删除题目不会丢失原文件定义的列；缺失字段显示“—”，`null`、`false`、`0`、空字符串及嵌套对象/数组分别展示。长值在列表缩略，完整值可点开详情查看；字段较多时可横向滚动。

勾选、序号、专家建议、审核/建议状态和操作作为审核功能列保留，不写入题目 JSON。可点击问题字段或“查看详情”打开题目；修改时新增的 key 会补入列，某题移除字段后该单元格显示“—”。支持搜索所有题目字段的名称和内容，按专家建议及审核状态筛选，每页可显示 20、50 或 100 题。审核页不再提供难度和任务族筛选；保留“全部字段 / 仅看字段缺失”筛选。上方统计显示题目总数、已通过/已提交建议、识别提示，不再展示任务族统计卡片。

点击题目或“查看详情”可查看 `Question`、`User Question`、`SELECT Data`、`answer`、`Scoring criteria`、`difficulty`、`Task family`、`source` 等全部字段。评分标准等嵌套对象和数组会展开显示，额外字段和 `null`、`0`、`false` 均保留。可切换上一题、下一题，查看或复制此题完整 JSON。缺少问题或参考答案的记录仍会保留，并标记“字段需确认”。

每道题增加“专家建议”列，题目详情的首个区块展示完整建议、提交时间和历史记录。可按“有专家建议”“暂无专家建议”“建议提交后已修改”筛选，也可搜索已提交的建议正文。切回页面时会刷新列表或正在查看的题目详情；正在修改题目、选择通过版本或确认删除时保留当前操作。

两个审核页上传后会自动打开“字段配置”，列出全部实际 JSON key、类型和分类数量。可以为每个 key 填写最多 2,000 字的描述，并单独开启“分类筛选”；已有导入可点击题目列表右上角“字段配置”补充设置。配置按评测集保存，在两个审核页共享，刷新或重启后保留，同名的其他导入互不影响。描述显示在表头下方；启用分类后，点击该表头的下拉按钮，选择实际字段值即可筛选。类别较多时可搜索和翻页，多个表头筛选按“同时满足”组合，可通过题目列表上方的标签清除单项或全部筛选。

分类弹窗使用复选框多选，提供“全选本页”“清空勾选”和已选数量，搜索、翻页保留其他页面的勾选。同一字段多个分类按“任意满足”筛选，不同字段按“同时满足”组合。点击“应用筛选”才生效，“取消”保留原筛选；清空勾选后应用可解除当前字段筛选。

分类筛选与搜索、审核状态、分页及“全选当前筛选结果”共同生效，题目修改或删除后按最新值更新类别。文本、数值、布尔值、null、空字符串和字段缺失分别匹配，数组和对象按完整内容匹配（对象属性顺序不影响类别）。字段设置独立于原始题目和冻结快照，不写入导出题目 JSON，也不调用模型；其他页面修改了配置时会提示重新打开，避免覆盖。

题目详情提供三个操作：

- **修改**：默认按字段编辑，结构化字段使用 JSON，也可切换到“编辑完整 JSON”增减字段。保存后更新搜索、难度和任务族统计，当前内容回到待审核状态。并发编辑会检查题目修订号，防止旧页面覆盖新内容。
- **删除**：确认后从审核列表移除，其他题目保留原序号。原始上传文件和已冻结的题目内容仍会保留。
- **通过**：选择一个已有版本，或在弹窗中直接创建新版本，将当前已保存的完整题目加入该版本。缺少问题或参考答案时，需先修改补充后通过。

列表默认显示待审核题目，可切换“已通过”或“全部状态”。评测集与原始文件保存在本机，刷新或重启后可通过“当前评测集”切换历史上传。同名文件分别保存，不覆盖原件；“下载原始 JSON”始终提供上传时的完整原文件。审核操作不调用模型。

两个审核页均可在“当前评测集”下拉框旁点击“删除评测集”，核对文件名、当前题数和原始题数后确认。整份导入会从业务专家和技术人员审核中同步移除，题目及审核记录不再显示；已冻结版本中的快照、原始源文档和“源文件生成评测集”中的 JSON 保留。删除后切换到其他评测集，最后一份删除后显示上传入口。切回另一审核页时会刷新列表；删除前若题目、专家草稿或收录状态已更新，会拒绝旧的删除确认，需刷新后再核对。原始 JSON、修改记录和专家建议保留在本机归档，已删除的导入不再提供审核或下载接口。

同名文件重新上传会创建独立导入。由源文件生成的评测集删除审核副本后，可从“源文件生成评测集”再次“送入审核”，创建使用生成原文的全新副本，原副本的修改和建议不混入新导入；重复点击送审仍会去重。

列表左侧支持勾选多题。表头复选框全选或取消选择本页；“全选当前筛选结果”可选中跨页的全部匹配题目。翻页和修改每页条数保留勾选，切换评测集、搜索或筛选条件时清空勾选，工具栏显示当前已选数量，也可手动“清空选择”。

“批量删除”会确认题目数量和序号；“批量通过”可统一选择已有冻结版本，或直接创建新版本。批量操作会先检查所有选中题目的修订号与内容，再一次性保存；遇到已修改、已删除、缺少问题或答案、同版本已收录等冲突时，整批不执行，并给出原因。操作成功后自动更新统计和列表、清空勾选。冻结快照仍按原有规则保留。

## 冻结评测集

业务专家审核、技术人员审核和冻结评测集均提供“题量分布”区块。只可选择当前评测集已启用分类筛选的 key：选择一个字段显示横向条形图，显示各分类题数、占比及总样本数；再选择一个不同字段显示交叉分布矩阵，显示每个组合的题数和占总样本比例，并列出行、列合计。分类顺序按题目中首次出现的顺序排列，条长按题数相对最大类别线性缩放。

“统计范围”可选当前筛选结果（包含搜索、审核状态及分类筛选，覆盖全部页）或全部保留题目。切换问题列表页码不会改变统计总量；筛选条件或题目内容更新后会刷新已选择的图表。审核页按最新保留题目统计，冻结页按当前版本保留的快照统计；字段描述、图表选择和统计结果不写入评测题 JSON，不调用模型。

空样本显示明确提示。分类较多时，条形图每页展示 20 类，矩阵每页展示 20 个行分类和 10 个列分类，可分别翻页，完整分类参与统计。矩阵合计覆盖对应分类在全部行列中的题目，不只计算当前显示区域。null、字段缺失、空字符串、数值及布尔值分别统计，数组和对象按完整内容分类。

打开 http://127.0.0.1:8765/frozen-datasets ，点击“创建版本”，填写唯一版本名称和可选说明。点击版本卡片可切换并查看已收录的题目，支持搜索、筛选、分页和完整详情。

版本列表表头按该版本第一道收录题目的实际 JSON key 和原顺序生成，两侧保留“序号”“操作”。首次收录确定的字段在搜索、翻页以及删除首题后保持一致。后续题目缺失的字段显示“—”；其他额外字段仍完整保留在详情和导出 JSON 中。字段较多时可横向滚动，操作列保持可见。

冻结页同步来源评测集在审核区保存的字段描述和“分类筛选”开关，已有版本也支持。点击带 `▾` 的字段表头可搜索、翻页和多选分类；同一字段满足任意选中分类，不同字段同时满足，也可与搜索、难度、任务族及分页组合。列表上方展示已应用的字段筛选，可单独或全部清除。分类选项和计数取自当前版本保留的冻结快照，审核区后续修改题目不会改变这些值；删除冻结题目后分类计数随之更新。字段设置在审核区维护，修改后刷新冻结页生效；旧筛选对应的开关已关闭时会提示重新选择。

多来源版本在首题定义的列中继承相关来源启用的分类，同名字段任一来源启用即可筛选；描述优先采用首题来源的非空描述。审核副本删除后已保存的字段配置仍供冻结版本使用。分类筛选只改变列表视图，“导出 JSON”继续导出当前版本的全部保留题目，字段描述和筛选设置不写入题目。

版本保存每道题通过审核时的内容快照。之后在审核区修改或删除该题，不会改变已收录的内容。同一道题可以加入不同版本，但同一个版本不会重复收录或覆盖仍在其中的题目；修改后的题目需要选择其他版本收录。每个版本最多保留 10,000 道题，可继续从审核页加入其他新题。

每题“操作”中提供“删除”。核对版本和题目后确认，只从当前版本的列表及导出中移除该题，保留其他题目的序号、审核原题、专家建议和其他版本快照。如果当前题目未在其他有效版本中通过，会回到待审核状态，可以重新通过后加入该版本。删除前校验版本修订，防止旧页面删除变化后的版本内容；删除状态在刷新及重启后保留，本机工作流中保留已删除题目的归档。

选择版本后，点击“导出 JSON”旁的“删除版本”，核对弹窗中的版本名称和题目数量，再点击“确认删除”。此版本及其收录记录会从冻结列表、导出和审核通过的版本选择中移除，审核原题、专家建议及其他版本保留。仅收录在被删版本中的题目会重新显示为待审核；仍收录在其他有效版本的当前题目继续显示已通过。删除最后一个版本后可重新创建，已删除的名称可再次使用。删除前校验版本修订，若其他页面已新增题目则拒绝按旧信息删除，需刷新后重新核对。本机工作流文件保留带删除标记的版本快照。

“导出 JSON”按收录顺序导出该版本的题目数组，保留原题字段、嵌套评分标准及数据类型，不把内部审核记录混入题目。版本和审核记录保存在本机，重启后仍可使用。

## 支持的接口

使用 OpenAI 兼容的 Chat Completions 协议：`POST /chat/completions`，请求包含 `model`、`messages` 和 `stream: false`。设置 API Key 时以 `Authorization: Bearer ...` 发送。接口格式参考 [OpenAI 官方文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。

地址规则：

| 填写地址 | 实际测试地址 |
| --- | --- |
| `http://127.0.0.1:8000` | `http://127.0.0.1:8000/v1/chat/completions` |
| `https://your-service.example/v1` | `https://your-service.example/v1/chat/completions` |
| `https://your-service.example/compatible-mode/v1` | `https://your-service.example/compatible-mode/v1/chat/completions` |
| `https://your-service.example/v1/models` | `https://your-service.example/v1/chat/completions` |
| `https://your-service.example/v1/chat/completions` | 原地址 |

界面会预览实际地址。模型名称使用服务端实际配置的 ID 或部署别名。当前版本不支持原生 Anthropic、Gemini、Responses API 或需要自定义鉴权头的接口。

只有接口成功返回有效的模型文本回复才显示测试成功；单纯 HTTP 200 或空回复不算成功。卡片状态表示最近测试的单个模型结果，悬停可查看测试模型和时间。修改连接配置后旧状态失效，需重新测试并保存。测试用于验证模型调用能力，不测试模型的 function calling 能力。每次点击会调用一次模型，按服务方的规则计费。源文档生成使用相同协议，额外发送 `temperature` 与 `max_tokens` 设置；自动运行评测与评分尚未实现。

## 本地运行与开发

无须安装 npm 依赖。需要 Node.js 22 或更新版本，加入 PATH 后即可使用；也可通过 EVAL_NODE 指定启动脚本使用的 Node.js 可执行文件。

文件预览和源文档提取需要 Python 3.10+ 及 `requirements.txt` 中的依赖。使用 `EVAL_PYTHON` 指定的 Python，或 PATH 中的 Python（Windows 为 `python`，其他系统为 `python3`）。安装依赖：`python -m pip install -r requirements.txt`。测试依赖安装：`python -m pip install -r requirements-dev.txt`。

```powershell
node server.mjs
node --test tests/*.test.mjs
```

默认仅监听 `127.0.0.1:8765`。如端口被占用，可设置环境变量后启动：

```powershell
$env:PORT = '8766'
.\start.ps1
```

- `public/`：界面、样式及交互。
- `server.mjs`：本地 API 代理与静态页面服务。
- `providers.mjs`：模型配置、Windows 密钥保护与测试状态管理。
- `prompts.mjs`、`public/prompt-utils.js`：提示词模板保存与变量替换。
- `data/prompts.json`：提示词库；删除的模板保留归档记录。
- `reviews.mjs`、`review-data.mjs`、`public/review-utils.js`：评测集导入、结构识别、逐题查询与字段映射。
- `data/technical-reviews/`：评测集索引与原始 JSON 文件，禁止从静态地址直接访问。
- `public/expert-review.html`、`public/expert-review.js`：业务专家审核界面与建议保存、提交；与技术审核共用列表、详情和多选逻辑。
- `data/technical-reviews/workflow.json`：题目修改、删除标记、冻结版本、题目快照、专家建议草稿与提交历史；审核通过与版本收录、专家提交与题目回到待审核，分别在一次原子写入中保存。
- `files.mjs`、`preview_file.py`：本地文件保存与内容预览。
- `generations.mjs`、`generation-data.mjs`：后台生成、分批计划、结构校验、继续生成与送入审核。
- `generation-source.mjs`、`extract_sources.py`：源文档完整提取，不复用截断预览。
- `public/source-generation.js`、`public/source-datasets.*`：源文件多选、生成设置、进度和结果页面。
- `data/generations/`：生成任务索引、已校验的分批结果和最终 JSON；保存源文件哈希、来源位置及提示词快照，不保存 API Key，也禁止静态访问。
- `data/files/`：文件索引及原文件副本，禁止从静态地址直接访问。
- `data/providers.json`：模型配置与加密后的密钥；不包含明文密钥。删除的配置保留归档记录。
- `data/config.json`：旧版非密钥配置，迁移后仍保留原文件。
- `tests/*.test.mjs`：本地模拟接口的自动化测试，不消耗真实模型额度。

自动测试使用生成的虚构样例文档，不读取运行数据。开发测试样例生成脚本额外使用 `reportlab`，已列入 `requirements-dev.txt`。测试密钥均为本地模拟字符串，不对应任何真实模型账号。

`tests/generations.test.mjs` 使用模拟模型验证分批生成、字段和引用校验、失败/停止/重启后的继续生成、模板变量、密钥脱敏及幂等送审；`tests/generation-source.test.mjs` 验证多工作表、长单元格、长文本、完整 Word、PDF 后续页面和 JSON/JSONL 的提取。`tests/generation-ui-fixture.mjs` 可启动独立的本地模拟模型和测试工作台（18878/18879 端口）进行浏览器验收，数据单独保存在 `test-results/generation-ui-*`，不读取客户配置。
